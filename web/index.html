Setup

Keys and credentials

Saved to a .env file on this machine and never sent anywhere except to the service each one belongs to. Existing values show masked — leave a field blank to keep what's already there.

Gemini Required

The classifier. Create a key at aistudio.google.com/apikey in a new project, and don't attach a billing account — with no payment method on the project there is nothing to charge.

YouTube Music Required

Google sign-in needs your own OAuth client. Free, a few minutes: create a project in the Cloud console, enable YouTube Data API v3, then create an OAuth client of type TV and Limited Input devices.

Last.fm Optional

Pulls community tags like chill or workout, which measurably help on songs the model doesn't know. Leave blank and everything still works. Get a key — free and instant.

Claude fallback Optional

If the claude CLI is installed and signed in, the app switches to it when Gemini hits its daily quota. Nothing to configure.

The CLI prefers ANTHROPIC_API_KEY if one is set in your environment, which bills per-token API credits instead of your subscription. Unset it if you want subscription billing.

Step 01

Connect YouTube Music

Sign in with Google, or paste browser headers if you'd rather not create an OAuth client. Either way, credentials stay on this machine.

How it works

  1. Press Start sign-in — you'll get a short code.
  2. Open Google's device page and enter that code.
  3. Approve access to your YouTube account.
  4. Come back here. The app picks it up on its own.

Your Google password never reaches this app. It receives a token you can revoke at any time from your Google account's security settings.

No OAuth client configured yet. Add a client ID and secret on the Setup screen first — it's free and takes a few minutes.

Getting your headers

  1. Open music.youtube.com while logged in.
  2. Open DevTools with ⌥⌘I and select the Network tab.
  3. Filter for browse, then click a playlist in the sidebar so a request appears.
  4. Open a POST request, go to Headers, and copy everything under Request Headers.
  5. Paste it opposite. The Cookie line has to be included.

Copy the headers, not the request URL. That mix-up is what produces the Expecting value: line 1 column 1 error.
